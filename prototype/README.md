## brep-probe.mjs

Разведка B-Rep-ядра, блок F. Геометрию оно строит верно — объём одной плитки
сходится с эталоном, — но одна склейка сетки 8 × 4 занимает 45 с при тайм-ауте
15, и быстрее не делается. Итог записан в PROGRESS.md, построение вернулось на
manifold с плоскими контурами (`src/geometry/outline.js`).

Зависимости из проекта убраны, скрипт лежит как запись: чтобы запустить,
нужно `npm install brepjs occt-wasm`. Ветка с рабочим B-Rep-построением —
`brep-engine`.
